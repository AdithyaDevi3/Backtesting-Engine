# Personal use

AlphaTest is designed for local research and education. You are responsible for market-data licensing, data accuracy, strategy assumptions, and any decisions made from its output. The project provides no uptime, support, execution-quality, or profitability guarantees.

Backtests can materially overstate real performance because the current simulator omits slippage, liquidity constraints, taxes, corporate-action modeling, and intraday price movement. Validate results independently before using them outside experimentation.
